# OpenCV Motion Game

## 프로젝트 소개
OpenCV를 활용한 실시간 모션 인식 및 타겟 색상 풍선 터트리기 게임

##  사용 기술
- C++
- OpenCV

## 핵심 구현 내용
1. 차분 영상을 이용한 움직임 감지
   - 이전 프레임과 현재 프레임의 그레이스케일 차이를 계산하여 변화가 있는 영역 검출
   - GaussianBlur와 Morphology 연산을 통해 웹캠 노이즈 최소화
2. 효율적인 충돌 판정
   - 풍선 위치의 ROI(Region of Interest) 내에서 유효 픽셀(Non-zero)의 밀도를 계산하여 성능 최적화
3. 사용자 경험(UX) 고려
   - 오답 시 화면 붉은색 플래시 효과 및 비프음 피드백
   - 콤보 시스템을 통한 게임성 부여
